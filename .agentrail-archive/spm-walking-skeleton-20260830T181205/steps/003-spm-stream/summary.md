Built components/stream/: five crates giving sequential parameter access and the metrics that make the architecture falsifiable. WeightStream exposes next_block/rewind and nothing that can express a position; documented precisely that this guarantees consumers cannot seek, not that implementations cannot. Measured rustdoc's compile_fail rather than trusting it: the harness is live (compiling code inside it fails the test) but the compile_fail,E0599 error-code pin is inert under Rust 2024 merged doctests, so a claim that the test 'fails for the right reason' would have been false. Kept the doctest with its limitation written down and added tests/surface.rs as the enforced tripwire. Added spm-stream-groups (not in the original sketch) so groups can be walked over bytes still arriving rather than a file already in RAM; its resident_parameter_bytes makes Rp a measurement. eta defined as storage_time/compute_time; Ps pinned to exactly 1.0 at batch 1 and 32.0 at batch 32 with storage bandwidth unchanged. Ratios return Option so a zero denominator reports unknown rather than a false zero. File and memory backends asserted byte-identical across capacities 1..4096 crossed with block sizes 1..4096. KNOWN LIMITATION: the file backend's two buffer slots are the seam for a prefetch thread or io_uring, but the refill is synchronous today so IO is not overlapped; stated in the crate docs and README rather than implied otherwise. 23 tests, 58 across the repo, 0 warnings, no #[allow].
