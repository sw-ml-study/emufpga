Consumed a frozen calibration-only Gemma-4 profile in a real bounded 512 MiB userspace expert-byte cache and ran 48 corrected cold physical replays across c1/c2/c4/c8 and demand/static/warm/adaptive policies. All policy digests matched. Static achieved 12.6-15.9% hits but increased device reads 8.4-9.8%; warm achieved 23.4-27.6% hits but increased reads 18.4-22.0%; adaptive matched demand because the short windows had no third reuse. Corrected and discarded an initial warmup-window sample using recorded request timestamps. Conclusion: multi-agent traversal sharing remains valuable, but broad speculative preload is a negative result for short cold sessions. Next: measure a long-lived demand-admitted shared cache and its break-even lifetime. Blockers: no multi-SAS hardware on this host; replay validates expert bytes rather than matrix arithmetic.
