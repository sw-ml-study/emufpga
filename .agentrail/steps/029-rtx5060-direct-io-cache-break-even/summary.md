Implemented a fail-closed controlled page-cache-bypass expert source using verified POSIX_FADV_DONTNEED between batches while preserving a bounded 128 MiB userspace cache. Three paired six-batch held-out c4 runs produced identical expert-byte digests. Admit-on-second-use broke even on physical bytes at batch two in every run and reduced physical reads 4.8% +/-2.2 percentage points, expert-read wait 5.1% +/-2.5, and elapsed time 4.5% +/-2.1. This contrasts with zero physical savings when Linux page cache can retain the file. Documented that this is a controlled fadvise proxy and byte replay, not O_DIRECT or inference. Updated checked data, README, docs and live graphics. Next: integrate the demand cache interface with complete inference and measure correct tasks rather than byte replay.
