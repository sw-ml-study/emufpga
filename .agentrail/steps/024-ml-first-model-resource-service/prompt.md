Prototype the Serial Parameter Machine as a Linux user-space model resource service suitable for later integration into an ML-first operating system. Define content-addressed model/tensor/expert resources, immutable execution-order weight streams, bounded residency contracts, mutable per-request KV and activation resources, tier capabilities for HDD/SSD/PMEM/RAM/VRAM, and a data-centric scheduler that batches routed activations around resident or passing experts. Use safe verified formats rather than executable serialization. Implement the smallest measurable service using existing Linux facilities such as io_uring or bounded asynchronous reads, cgroups, NUMA policy, shared-memory queues, and GPU APIs; do not require a new kernel. Compare independent process demand paging with shared expert scheduling for multiple clients, recording bytes, reuse, memory, quality, latency, energy, and fairness. Document the kernel-facing interfaces that would become first-class OS primitives only after the user-space value is measured. Run the project gate, commit to main, push, and update the live visualization.
